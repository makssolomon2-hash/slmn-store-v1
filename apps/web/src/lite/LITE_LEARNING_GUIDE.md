
# 🚀 SLMN Sound - Lite Version Learning Guide

Welcome to the **Lite Version**! This isolated, beginner-friendly section of the codebase was created to help you understand the fundamental concepts of React, Tailwind CSS, and PocketBase without being overwhelmed by the complexity of the main application.

---

## 📁 1. Folder Structure Explained

All code for this version lives exclusively inside `apps/web/src/lite/`. Think of it as an app *within* an app.
